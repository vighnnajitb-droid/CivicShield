# CivicShield — Evidence-Backed Government Accountability & Access to Justice
*"A complaint supported by evidence should not disappear without a trace, and an unresolved case should not be silently buried."*

Track: Social Impact · Stack: React (no-build, CDN) · FastAPI · SQLite (Postgres-ready SQL) · **n8n as the process engine**

## 1. Quick start
**Docker (recommended):** `cp .env.example .env`, set `JWT_SECRET` and `INTERNAL_API_KEY`, then `docker compose up --build`.
Then import + activate workflows (once):
`docker compose exec n8n n8n import:workflow --separate --input=/workflows && docker compose exec n8n n8n update:workflow --all --active=true && docker compose restart n8n`
(or n8n UI → Workflows → Import from file → each file in `n8n-workflows/` → toggle **Active**).

**Without Docker:** `export INTERNAL_API_KEY=...; ./run_n8n_local.sh` (terminal 1), `./run_local.sh` (terminal 2).

- App: http://localhost:8000 · API docs (Swagger): http://localhost:8000/docs · n8n: http://localhost:5678
- The DB is created and demo data seeded on first start.

## 3. Architecture
```
React UI ──► FastAPI (auth, RBAC, data, hash-chain) ──► SQLite
                │  ▲                                        ▲
   webhooks     ▼  │ /internal API (X-Internal-Key)         │
            n8n workflows ── LLM (optional) / mock AI ───────┘
   intake · ai · evidence · audit · assignment · monitor(cron) · escalation · notify · duplicates · appeal · legal · summary
```
Division of labour: **the backend owns data and authorization; n8n owns every business process.** n8n never touches the DB directly, so it cannot bypass RBAC or the audit chain; it calls a key-protected `/internal` API.

## 4. What n8n actually executes (`n8n-workflows/`, generated by `tools/gen_workflows.py`)
| File | Trigger | Does |
|---|---|---|
| complaint_intake | POST `/webhook/complaint-created` | validate → advisory AI triage → duplicate-check → authority assignment (+deadlines) → audit event → notification → result |
| ai_analysis | POST `/webhook/ai-analysis` | loads complaint + evidence metadata → similarity check → LLM (if `OPENAI_API_KEY`) **or** mock AI → guilt-language guard-rail → labelled advisory report |
| evidence_processing | POST `/webhook/evidence-uploaded` | type + magic-byte + size validation, **SHA-256**, evidence ID → backend stores privately + audit |
| audit_trail | POST `/webhook/case-event` | re-verifies the hash chain after every action; tamper → alert to admin; else fans out notifications |
| authority_assignment | POST `/webhook/authority-assignment` | category→department, jurisdiction→office, sets ack/review/resolution deadlines |
| deadline_monitor | **Schedule (5 min)** + POST `/webhook/deadline-monitor-run` | finds overdue/approaching deadlines → calls escalation per case / warns |
| automatic_escalation | POST `/webhook/escalate-case` | re-checks condition; moves **only** to the configured parent authority; top of hierarchy → legal assistance |
| notifications | POST `/webhook/notify` | in-app + simulated Email/WhatsApp/SMS (+ optional real SMTP node) |
| duplicate_detection | POST `/webhook/duplicate-check` | flags similar complaints for human review, never rejects |
| appeal_processing | POST `/webhook/appeal-submitted` | confirms appeal, chain check, audit, notify |
| legal_assistance | POST `/webhook/legal-assistance` | summary + general options + free/low-cost provider filter + checklist + disclaimer |
| case_summary | POST `/webhook/case-summary` | full structured case summary |

**Env vars n8n needs:** `BACKEND_URL`, `INTERNAL_API_KEY`, `N8N_WEBHOOK_BASE`, `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`, `NODE_FUNCTION_ALLOW_BUILTIN=crypto`; optional `OPENAI_API_KEY/OPENAI_MODEL/OPENAI_BASE_URL`, `SMTP_ENABLED`, `SMTP_FROM`, `NOTIFY_FALLBACK_EMAIL`.
**Credentials:** none required for the demo. Optional: an SMTP credential on the "Send Email" node (set `SMTP_ENABLED=true`).
**Database connections:** none from n8n by design (it uses the backend API).
If n8n is down, the backend records a `pending` row in `workflow_runs` (Admin → workflows → *retry*); AI/evidence calls return a clear 503. Nothing silently pretends n8n ran.
Why user actions write the audit event in-backend *and* call n8n: the hash-chain append must be in the same DB transaction as the action; n8n then independently verifies it and handles fan-out.

## 5. Tamper-evident audit
Per complaint: `current_hash = SHA-256(canonical JSON of event_id, complaint_id, actor_id, timestamp, event_type, previous_hash, metadata)`, first `previous_hash` = 64 zeros. SQLite triggers reject UPDATE/DELETE on audit events, complaints (delete / original text), evidence, decisions, responses, status history and escalations. Corrections are new rows; decisions are superseded, never edited.

## 6. Security summary
PBKDF2-SHA256 (210k) password hashing · JWT with expiry · role checks on every route (`require(...)`) · object-level checks (`can_view`) · evidence: allow-list, magic-byte sniffing, size cap, random server-side names, never served publicly, every access audited, admin/legal-aid cannot download files · masked phone/email for officials · citizens never see other citizens' duplicates · self-registration = citizen only · no hard-coded secrets (random ephemeral fallback + warning) · internal API protected by constant-time key compare · AI output sanitised of guilt language.

## 9. Testing — what was actually run (see §10 of docs/HACKATHON.md)
`python -m unittest tests.test_core` (15 domain tests) and `python tests/e2e.py` (54 checks over HTTP). **Important limits:** the build sandbox had no internet, so FastAPI, uvicorn, React CDN and n8n could not be installed. The e2e test therefore uses (a) `tests/harness/fastapi/` — a tiny stand-in that runs the real `app/main.py` handlers, and (b) `tests/harness/n8n_sim.js` — a subset interpreter that executes the real workflow JSON (nodes, expressions, Code-node JS). They validate logic and wiring, **not** real-FastAPI/real-n8n/browser behaviour. Please verify once on your machine: start real n8n + real uvicorn and walk through the three demo scenarios by hand (`USE_REAL_N8N=1 python backend/tests/e2e.py` skips the n8n simulator but still serves the backend through the stand-in, so it only covers real n8n, not real FastAPI).
